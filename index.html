PulseLab Studio Guide

Gumamit ng Earphones / Headphones!

Para hindi bumalik sa mic ang backing beat o naunang track habang nag-o-overdub ka sa phone o PC.

Paano Gamitin

  1. Pindutin ang R sa track na gusto mong pag-recordan (o mag-import ng backing beat gamit ang Import Beat).
  2. Pindutin ang Rec button sa taas para magsimula (may 4-beat count-in).
  3. Mag-add ng panibagong track at i-arm ang R para mag-layer ng vocals, harmonies, o instrumento.
  4. I-click kahit saan sa waveform timeline para ilipat ang playhead, at i-click ang Export .WAV kapag tapos na.
